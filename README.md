# Aelderia: pre-generated player characters

Twelve ready-to-play characters (one per class), levels 1 to 10. 2024 rules / SRD 5.2.1.

- Class pages: https://oberonandomegaid.github.io/aelderia/characters/
- Sheets (PDF, with portrait): `characters/pdf/<class>/<class>-level-XX.pdf`
- One-shot handouts (3 pages, 4 characters a page, QR to each sheet):
  - PDF: `characters/handouts/Aelderia_Pregens_Level_XX.pdf`
  - Page images for Homebrewery: `characters/handouts/pages/level-XX-page-N.jpg` (N = 1 to 3)
