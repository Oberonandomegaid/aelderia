# Project Freedom: pre-generated player characters

Twelve ready-to-play characters (one per class), levels 1 to 10. 2024 rules / SRD 5.2.1.

- Class pages: https://oberonandomegaid.github.io/project-freedom/characters/
- Sheets (PDF, with portrait): `characters/pdf/<class>/<class>-level-XX.pdf`
- One-shot handouts (3 pages, 4 characters a page, QR to each sheet):
  - PDF: `characters/handouts/Project_Freedom_Pregens_Level_XX.pdf`
  - Page images for Homebrewery: `characters/handouts/pages/level-XX-page-N.jpg` (N = 1 to 3)

Includes material from the System Reference Document 5.2.1 by Wizards of the Coast LLC, licensed CC BY 4.0. Original characters by Project Freedom.
